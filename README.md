# MVスタジオ（SYNC_MVStudio）

歌詞1フレーズの配置とアニメーションを作るAviUtl2用フィルタープラグインです。
グループは `SYNC`、表示名は `MVスタジオ`。Google Skiaで文字を描画します。
専用編集画面への移行を進めています。標準モードは既存データの互換用に残しています。

## 使い方

1. シーンと同じ大きさのフィルターオブジェクトへ「MVスタジオ」を追加します。
2. AviUtl2の「歌詞」へ入力して「拡張編集」を開きます。新規サイズは100pxです。
3. 文字をクリックすると8点のハンドルが出ます。内部をドラッグして移動、四隅で比率を保った拡縮、
   上下左右の辺で縦横別の拡縮、上へ伸びた丸いハンドルで回転します。
   ホイールで表示をズームし、中ボタンドラッグまたはSpace+左ドラッグで画面を移動できます。
   背景には直前に取得した入力映像の静止画を表示します。背景が無地の場合は、
   AviUtl2で対象フレームを表示してから拡張編集を開き直してください。
4. Aアイコンでフォント・文字色・縁・影・間隔・演出を設定します。文字サイズは出力画像上のpx単位です。
5. ×またはチェックマークの「閉じる・確定」で保存し、AviUtl2側で再生して確認します。
   初回確定時は標準の見た目を取り込んで拡張モードへ切り替わります。
   歌詞を変更すると共通する先頭・末尾の配置を保持し、新しい文字を自動配置します。
   元に戻す／やり直すはアイコンとCtrl+Z／Ctrl+Y・Ctrl+Shift+Zに対応します。

磁石アイコンで位置・角度のスナップを切り替えます。Altで一時解除、Shift+回転で15度刻みになります。
矢印キーは1px、Shift+矢印は10px移動。Escは操作取消、Ctrl+0は全体表示、Ctrl+1は100％表示です。

登場・退場時間は両モードともAviUtl2側の項目です。
今回の画面で確定した拡張文書は、フォント・装飾・演出を専用画面側で管理します。
旧データも読込可能です。再確定するまでは従来どおりホスト設定に従います。

登場/退場はフェード・スライド・ズーム・ポップ・回転・文字送り、表示中は浮遊・脈動・波・揺れを選べます。
文字ごとの時間差、共通の縁・影・字間・行間にも対応します。
「標準の登場／表示中／退場」は標準モードと旧データとの互換性のため残しています。
旧版で編集画面だけへ入力した歌詞は、AviUtl2の「歌詞」項目へ入力してください。
範囲装飾、高度な演出、プリセット、編集背景の動画再生はまだ実装していません。
AviUtl2本体での操作・保存再読込は別途実機確認が必要です。

## 開発

Delphi 37.0 / Win64で `SYNC_MVStudio_Filter.dproj` をビルドします。
配備先は `C:\ProgramData\aviutl2\Plugin\SYNC_MVStudio`。
本体2.1.10未満では旧形式の編集ボタン、2.1.10以降では対象指定付きのボタンを使用します。
旧本体での拡張編集はオブジェクトごとに本効果1つに対応し、同一オブジェクトへの複数追加時は案内を表示します。
別々のオブジェクトへの配置には対応します。
